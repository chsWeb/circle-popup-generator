    How To Configure Each Line

    Line What it does How to edit it
    rootDomain Limits the popup to this Circle community domain. The script compares it to the current browser hostname before showing anything. Use the bare domain, not a path. Example: your-community.example.com.
    targetMode Controls whether the popup appears on specific paths or every page in the configured community. Use specific-paths to use the targetPaths list, or all-pages to show across the community domain.
    targetPaths Lists the exact Circle paths where the popup is allowed to appear. Used only when targetMode is specific-paths. The current value targets /feed.
    excludedPathPrefixes Hard-blocks the popup from Circle admin and message areas. This is set to /settings and /messages. Leave these exclusions in place.
    showTitle Controls whether the popup headline is shown. Use true to show the headline or false to hide it.
    title Controls the popup headline. Line breaks are preserved. Keep it short enough to fit on mobile.
    subtext Controls the paragraph under the headline. Line breaks and blank-line paragraph breaks are preserved. Use one asterisk for italic and two asterisks for bold.
    imageUrl Optional image shown inside the popup. Leave it blank to show no image. Use a full https image URL when adding one.
    imagePlacement Controls where the optional image appears. Use before-title or after-title. Those are the only supported values in this script.
    ctaText Controls the primary button label. This button marks the popup completed, sends tracking, then opens ctaUrl.
    ctaUrl Controls the destination for the primary button. Use the full survey or landing page URL, including https://.
    storageKey Controls the localStorage record used to remember completion, reminder, and dismissal state. Change this for a new campaign when you want people to see the popup again.
    trackingName Controls the Mixpanel popup_name property on popup events. Use a stable, lowercase campaign name that will be easy to filter in Mixpanel.
    remindDays Controls how long the popup stays hidden after Remind me later. The current value is 7 days.

    Mixpanel Tracking

    The script waits briefly for window.mixpanel.track before sending popup events. If Mixpanel never becomes available, the CTA still redirects.

    Community Popup Viewed Popup is displayed Base popup properties
    Community Popup CTA Clicked Primary button click cta_text, cta_url
    Community Popup Remind Later Clicked Remind me later button or outside click remind_days, remind_method
    Community Popup Declined X close button Base popup properties
