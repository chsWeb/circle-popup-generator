Questions

Do I need to know how to code?

No. You fill in a form and copy the result into Circle's custom code area. If you can paste text into a settings box, you can do this. The generated block is self-contained — there's nothing to edit by hand afterwards.

Where exactly does the code go in Circle?

Into your community's custom code settings, in the section that injects code into the page body. You'll get the exact steps after purchase. Saving it makes the popup live immediately on the pages you targeted.

Will members see the popup over and over?

No. The popup remembers each member's response in their browser. If they click the button or close it, they don't see it again. If they choose "remind me later," it stays hidden for the number of days you set, then returns once.

Do I have to use Mixpanel?

No. If Mixpanel is installed on your community, the events flow automatically. If it isn't, the popup works exactly the same and the tracking calls are simply skipped — they never delay or block your call-to-action.

Can I run popups on more than one community?

Yes. Your purchase unlocks the generator for your account, and you can generate as many blocks as you want for as many communities as you run. Each block targets one domain, so just generate one per community.

Will it show up somewhere awkward, like a member's inbox?

No. Settings and messages pages are permanently excluded, even if you choose to show the popup across your whole community. It also verifies the domain before doing anything, so the code can't fire outside your community.

Is this made or supported by Circle?

No. This is an independent tool, not built by Circle and not affiliated with them. It works through Circle's custom code area, which is a feature Circle provides — but Circle's support team can't help you with the popup itself.
